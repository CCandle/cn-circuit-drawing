# CN Circuit Drawing

面向国内电路教材、课程作业与技术文档的个人电路绘图规范与 AI Skill。

## 当前阶段：Demo 0.1（视觉核对）

本轮先交付图，不先冻结完整规范。当前三张图覆盖：

1. 基础元件与常用符号
2. 导线交叉、连接点、电流/电压标注、测量电路与运放跟随器
3. 耦合电感、互感弧线与变压器

绘图中明确区分两层：

- **符号基线**：按现行 GB/T 4728 对应分册的范围，以及国内电路教材常用表达进行首轮核对。
- **个人偏好候选**：弧形线圈、清楚的电表圆形表体、较小的独立源、短电流箭头、居中的电压量名、连续互感弧线、紧凑且对称的变压器布局，以及相对元件引脚定位的运放标注。

个人偏好不是国家标准条文，不会混写成强制要求。

## 仓库结构

- research/standards.md：公开标准目录、状态与本轮用途
- demo/demo.tex：首轮三页 CircuiTikZ 源文件

## 边界说明

本轮核对了官方公开目录中的标准编号、名称、现行状态与分册范围。部分采标标准的完整正文受版权限制，不能仅凭公开元数据声称已逐笔完成正式符合性认证。因此 Demo 0.1 是**有标准依据的视觉候选稿**，后续仍应以可合法获取的标准正文和实际教材样例逐项复核。
