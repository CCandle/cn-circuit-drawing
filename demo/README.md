# Demo 0.1

This is a three-sheet visual draft for review, not a frozen specification.

- sheet-1.tex — basic symbols
- sheet-2.tex — topology, measurement circuit, voltage annotation, op-amp follower
- sheet-3.tex — coupled inductors and transformer
- demo.tex — document entry point

The draft intentionally separates the GB/T 4728 symbol baseline from personal layout preferences. Any preferences that affect symbol recognition or electrical topology must be rejected rather than preserved.
